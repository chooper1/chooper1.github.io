Coleman Hooper

Contact: chooper@berkeley.edu

Research Interests: Efficient LLM Inference, AI Systems, Model Compression

I received my PhD from UC Berkeley in ML Systems, advised by Professors Kurt Keutzer in Berkeley AI Research (BAIR) and Sophia Shao in SLICE Lab (Computer Architecture group). I work on full-stack optimization for LLM inference, spanning efficient algorithms, ML systems, and architecture for ML.

research overview

Full-stack optimization. My work has centered around full-stack optimization of LLM inference workloads. My work has been driven by understanding and optimizing bottlenecks across hardware, systems, and algorithms. This work has been guided by our characterization of LLM workloads [Full-Stack (ISCA Workshop'23)] as well as memory bottlenecks in AI [AI and Memory Wall (IEEE Micro'24)].

LLM compression + long context inference. In my PhD, the bulk of my work focused on designing memory-efficient algorithms and systems for LLM inference. My work largely centered around accelerating LLM decoding by leveraging model compression [SqueezeLLM (ICML'24)] and speculative decoding [QuantSpec (ICML'25)]. I also worked extensively on accelerating long context inference workloads through KV cache compression [KVQuant (NeurIPS'24)], sparse + approximate attention algorithms [Squeezed Attn (ACL'25), Multipole Attn (NeurIPS'25)], and rematerializing the KV cache [XQuant (arXiv'25)].

Efficient reasoning & agents. I have also worked on accelerating LLM applications and alternative LLM architectures. I have designed efficient algorithms for LLM applications such as reasoning [ETS (arXiv'25), Arbitrage (arXiv'25), RCD (arXiv'26)] and agentic workloads [TinyAgent (EMNLP Demo'24), Squeeze Evolve (arXiv'26)].

Parallel and looped generation. Additionally, to tackle the limited inherent parallelism with LLM generation for small batch sizes [Beyond Next-Token Prediction (arXiv'25)], I have worked on alternative LLM architectures which can generate multiple tokens in parallel. I have explored diffusion language models in order to draft and iteratively refine multiple tokens in parallel [LoSA (arXiv'26), CDLM (MLSys'26)], as well as self-speculative decoding methods for looped transformers using earlier loops for drafting and later loops for verification [SPEED (Springer'25)].

LLM inference hardware. I have also worked extensively on inference hardware for LLM and Speech Processing Workloads. This includes accelerators and SoCs for noise-robust speech and NLP applications [ASR (Hot Chips'21, ISSCC'21, JSSC'22)] and for energy-efficient transformer inference [BERT (MICRO'21, ISSCC'23)]. I have also worked on co-designing quantization and sparsity algorithms with hardware for LLM inference [FGMP (arXiv'25), Sirius (VLSI'26)], and explored the potential of emerging memory technologies like Compute-in-Memory and High-Bandwidth Flash for LLM inference [LLM-in-a-Flash (arXiv'26), Characterizing HBF (arXiv'26)].

selected publications

  1. NeurIPS
    Multipole Attention for Efficient Long Context Reasoning
    Coleman Hooper*, Sebastian Zhao*, Luca Manolache, and 5 more authors
    NeurIPS, 2025
    Abs PDF

    While reasoning models have shown promising accuracy benefits through long chain-of-thought decoding, they exhibit substantial overhead at inference time due to the need to generate thousands of tokens. While sparse attention methods can help reduce the KV cache pressure induced by this long autoregressive reasoning, these methods can introduce errors which disrupt the reasoning process. In this work, we introduce Multipole Attention, which accelerates autoregressive reasoning by only computing exact attention for the most important tokens while maintaining approximate representations for the remaining tokens, achieving up to 4.5x attention speedup for long context reasoning.

  2. ACL
    Squeezed Attention: Accelerating Long Context Length LLM Inference
    Coleman Hooper*, Sehoon Kim*, Hiva Mohammadzadeh, and 6 more authors
    ACL, 2025
    Abs PDF Code

    In this work, we aim to accelerate long context length applications where much of the input context in the prompt is fixed across different user inputs. Our approach preprocesses the fixed context KV cache ahead of inference time by applying K-means clustering to group the keys based on semantic similarity and represent each cluster with a single centroid value. At inference time, we first compare the query with the key centroids to identify important KV cache entries, and then only compute exact attention using only the important keys, thereby achieving 8X reduction in KV budget and >4x speedups with minimal accuracy loss.

  3. NeurIPS
    KVQuant: Towards 10 Million Context Length LLM Inference with KV Cache Quantization
    Coleman Hooper, Sehoon Kim, Hiva Mohammadzadeh, and 4 more authors
    NeurIPS, 2024
    Abs PDF Code

    In this work, we identify the KV cache as the critical memory bottleneck when scaling to long context lengths with LLM inference. We then design a KV cache quantization strategy which retains accuracy with aggressive ( 5x) compression by incorporating several novel methods: (i) Per-Channel Key Quantization, (ii) Pre-RoPE Key Quantization, (iii) Non-Uniform KV Cache Quantization, and (iv) Per-Vector Dense-and-Sparse Quantization. Our method achieve < 0.1 perplexity degradation with 3-bit quantization and gets up to  1.7x speedups.

  4. ICML
    SqueezeLLM: Dense-and-Sparse Quantization
    Sehoon Kim*, Coleman Hooper*, Amir Gholami*, and 5 more authors
    ICML, 2024
    Abs PDF Code

    In this paper, we highlight memory bandwidth as a critical bottleneck for single batch LLM inference rather than computation. Building on this observation, we design a quantization strategy which aggressively reduces the memory requirements (at the expense of a small amount of additional computation). We achieve accurate low-precision (3-bit) quantization by incorporating (i) sensitivity-based non-uniform quantization and (ii) dense-and-sparse decomposition, which together allow our method to retain close to the baseline accuracy while achieving 2.3x speedup.
